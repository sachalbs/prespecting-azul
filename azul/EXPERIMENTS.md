# Expériences

Une expérience = une variable, déclarée AVANT l'envoi, tranchée par un chiffre.
Jamais plus d'une expérience active par segment.

## Template

```
### EXP-XXX · titre court
Segment    : SEG-XX
Hypothèse  : "X fera mieux que Y parce que Z" (falsifiable)
Variable   : objet | angle | CTA | longueur | canal | heure
Contrôle   : description exacte du bras A
Variante   : description exacte du bras B
Taille     : n par bras (≥ 10, idéalement 20)
Statut     : déclarée | en cours | tranchée
Résultat   : taux A vs taux B (n) → décision (promue / archivée)
```
